## 🎨 DESIGN SYSTEM & AESTHETIC DIRECTION

### Theme: "Neural Dark" — Dark Intelligence

 **Concept** : The portfolio IS an AI system. Visitors feel like they're interfacing with a sophisticated neural network — not reading a brochure.

### Color Palette

```
Background:     #020608  (near black, not pure black — depth)
Surface:        #0A0F14  (dark cards)
Border:         #1A2332  (subtle blue-dark)
Primary:        #00D9FF  (electric cyan — AI energy)
Secondary:      #7B2FFF  (deep violet — intelligence)
Accent:         #FF6B35  (orange — human warmth, differentiator)
Text Primary:   #F0F4F8
Text Secondary: #8BA3B8
Success:        #00FF9D  (terminal green — execution)
```

### Typography

```
Display:     "Space Grotesk" or "Syne" — geometric, technical
Mono/Code:   "JetBrains Mono" — for code snippets, terminal effects
Body:        "DM Sans" — clean, readable
Accent:      "Bebas Neue" — for section labels/numbers
```

### Visual Language

* Subtle noise/grain texture on background
* Glowing cyan borders on hover (box-shadow: 0 0 20px #00D9FF40)
* Grid lines faintly visible in hero (like a coordinate plane)
* Neural network node particle system (Three.js or canvas)
* Cursor: custom crosshair that trails
* Scroll: Lenis smooth scroll
