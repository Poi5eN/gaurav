### Video Support with Image Fallback

```tsx
// ProjectMedia.tsx
interface ProjectMediaProps {
  videoUrl?: string        // mp4 or webm — optional
  imageUrl: string         // always required as fallback
  projectTitle: string
}

export function ProjectMedia({ videoUrl, imageUrl, projectTitle }: ProjectMediaProps) {
  const [videoFailed, setVideoFailed] = useState(false)
  const [isHovered, setIsHovered] = useState(false)
  const videoRef = useRef<HTMLVideoElement>(null)

  useEffect(() => {
    if (videoRef.current) {
      if (isHovered) videoRef.current.play()
      else { videoRef.current.pause(); videoRef.current.currentTime = 0 }
    }
  }, [isHovered])

  if (!videoUrl || videoFailed) {
    return (
      <img
        src={imageUrl}
        alt={projectTitle}
        style={{ width:'100%', height:'200px', objectFit:'cover', borderRadius:'8px' }}
        loading="lazy"
      />
    )
  }

  return (
    <div
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      style={{ position:'relative', borderRadius:'8px', overflow:'hidden', height:'200px' }}
    >
      <video
        ref={videoRef}
        src={videoUrl}
        muted
        loop
        playsInline
        onError={() => setVideoFailed(true)}
        style={{ width:'100%', height:'200px', objectFit:'cover' }}
      />
      {/* Play indicator overlay */}
      {!isHovered && (
        <div style={{
          position:'absolute', inset:0, display:'flex', alignItems:'center', justifyContent:'center',
          background:'rgba(0,0,0,0.3)',
        }}>
          <div style={{
            width:40, height:40, borderRadius:'50%', background:'rgba(0,217,255,0.2)',
            border:'1px solid #00D9FF', display:'flex', alignItems:'center', justifyContent:'center',
          }}>
            ▶
          </div>
        </div>
      )}
    </div>
  )
}
```

```tsx
import { Canvas, useFrame } from '@react-three/fiber'
import { useRef } from 'react'

function TorusKnot() {
  const ref = useRef<any>()
  useFrame(({ clock }) => {
    ref.current.rotation.x = clock.getElapsedTime() * 0.12
    ref.current.rotation.y = clock.getElapsedTime() * 0.18
  })
```

```html
<h2>The Problem Nobody Warns You About</h2>
<p>I've built a RAG pipeline twice now. The first time, I followed the LangChain quickstart tutorial and shipped a demo in 4 hours. It worked great on my 10-page test PDF. Then we gave it a 200-page insurance policy document and it completely fell apart.</p>
<p>Here's what actually goes wrong — and what actually fixes it.</p>

<h2>1. Chunking Is Everything (And Nobody Talks About It)</h2>
<p>The tutorial says: split your document into 500-character chunks with 50-character overlap. Fine. But what happens when a policy clause starts on page 47 and ends on page 48? You split it in half. The retriever finds the first half, LLM hallucination fills in the second half. Wrong answer. Confidently wrong.</p>
<p><strong>What I actually use:</strong> Semantic chunking with <code>langchain_experimental.text_splitter.SemanticChunker</code>. It uses embedding similarity to find natural break points in the text, not arbitrary character counts. Takes 3x longer to index, but retrieval quality goes from ~60% to ~88% on my test set.</p>

<h2>2. Your Retriever Is Probably Wrong Too</h2>
<p>Default top-k similarity search returns the k most similar chunks. Problem: if the answer requires combining information from chunks 1, 47, and 203 — you'll never get there with similarity alone.</p>
<p><strong>What I actually use:</strong> MMR (Maximal Marginal Relevance) retrieval. It balances relevance with diversity. You get both the most-similar chunk AND chunks that add new information. Implemented in one line with LangChain:</p>
<pre><code>retriever = vectorstore.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 6, "fetch_k": 20, "lambda_mult": 0.7}

<h2>3. The Context Window Isn't Your Enemy — Bad Retrieval Is</h2>
<p>When retrieval fails, people blame the LLM. "GPT-4 hallucinated again." Usually it's not the LLM. It's that you gave it 6 chunks that don't actually answer the question, and the model did its best with garbage input.</p>
<p>Add evaluation. I use RAGAS — an open-source framework that scores faithfulness, answer relevancy, and context recall. Run it on 20-30 representative questions before shipping. If faithfulness is below 0.85, fix your retriever before touching the prompt.</p>
```

```html
<li>Human review queue: if confidence < 0.75 or requiresHumanReview: true, route to a human assessor</li>
</ol>
<p>After these additions, accuracy on our test set: 91% match with human assessors. False positive rate: 4%. That's good enough to auto-approve minor claims and flag moderate/severe for review.</p>
```

```typescript
// app/api/ai-lab/route.ts
import OpenAI from 'openai'
import { KNOWLEDGE_BASE } from '@/data/ai-lab-knowledge'
import { NextRequest, NextResponse } from 'next/server'

const client = new OpenAI({
  baseURL: 'https://openrouter.ai/api/v1',
  apiKey: process.env.OPENROUTER_API_KEY,
  defaultHeaders: {
    'HTTP-Referer': 'https://itsgauravhere.netlify.app',
    'X-Title': "Gourav's Portfolio AI",
  },
})

export async function POST(req: NextRequest) {
  const { messages } = await req.json()

  const stream = await client.chat.completions.create({
    model: 'google/gemini-2.0-flash-exp:free',  // free tier on OpenRouter
    // Fallback models if free quota exhausted:
    // 'deepseek/deepseek-chat', 'meta-llama/llama-3.3-70b-instruct:free'
    stream: true,
    max_tokens: 600,
    messages: [
      {
        role: 'system',
        content: KNOWLEDGE_BASE,
      },
      ...messages.slice(-6),  // last 6 messages for context
    ],
  })

  // Stream response back to client
  const encoder = new TextEncoder()
  const readable = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        const text = chunk.choices[0]?.delta?.content || ''
        if (text) controller.enqueue(encoder.encode(text))
      }
      controller.close()
    },
  })

  return new Response(readable, {
    headers: { 'Content-Type': 'text/plain; charset=utf-8' },
  })
}
```

```tsx
// AILabChat.tsx — minimal, streaming chat widget
export function AILabChat() {
  const [messages, setMessages] = useState<{role:string, content:string}[]>([
    { role:'assistant', content:"Hi! I'm Gourav's portfolio AI. Ask me about his projects, skills, NEXUS, or experience." }
  ])
  const [input, setInput] = useState('')
  const [streaming, setStreaming] = useState(false)

  const SUGGESTIONS = [
    'Tell me about NEXUS',
    'What AI/ML experience does Gourav have?',
    'Show me his best projects',
    'What is the ReAct agent loop?',
  ]

  async function send(text?: string) {
    const msg = text || input
    if (!msg.trim() || streaming) return
    setInput('')
    const updated = [...messages, { role:'user', content:msg }]
    setMessages(updated)
    setStreaming(true)

    const res = await fetch('/api/ai-lab', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ messages: updated }),
    })

    const reader = res.body!.getReader()
    const decoder = new TextDecoder()
    let assistantMsg = ''
    setMessages(m => [...m, { role:'assistant', content:'' }])

    while (true) {
      const { done, value } = await reader.read()
      if (done) break
      assistantMsg += decoder.decode(value)
      setMessages(m => {
        const copy = [...m]
        copy[copy.length - 1] = { role:'assistant', content: assistantMsg }
        return copy
      })
    }
    setStreaming(false)
  }

  return (
    <div style={{ background:'#0A0F14', border:'1px solid #1A2332', borderRadius:12, overflow:'hidden' }}>
      {/* Suggestion chips */}
      {messages.length === 1 && (
        <div style={{ padding:'12px 16px', display:'flex', gap:8, flexWrap:'wrap', borderBottom:'1px solid #1A2332' }}>
          {SUGGESTIONS.map(s => (
            <button key={s} onClick={() => send(s)} style={{
              fontSize:12, padding:'5px 12px', borderRadius:20,
              background:'#00D9FF10', border:'1px solid #00D9FF30', color:'#00D9FF', cursor:'pointer',
            }}>{s}</button>
          ))}
        </div>
      )}
      {/* Messages */}
      <div style={{ height:320, overflowY:'auto', padding:16, display:'flex', flexDirection:'column', gap:12 }}>
        {messages.map((m, i) => (
          <div key={i} style={{
            alignSelf: m.role === 'user' ? 'flex-end' : 'flex-start',
            maxWidth:'80%', padding:'10px 14px', borderRadius:10,
            background: m.role === 'user' ? '#00D9FF15' : '#0F1923',
            border: `1px solid ${m.role === 'user' ? '#00D9FF30' : '#1A2332'}`,
            color:'#F0F4F8', fontSize:14, lineHeight:1.7,
          }}>
            {m.role === 'assistant' && streaming && i === messages.length - 1
              ? m.content + '▋'
              : m.content}
          </div>
        ))}
      </div>
      {/* Input */}
      <div style={{ display:'flex', gap:8, padding:'12px 16px', borderTop:'1px solid #1A2332' }}>
        <input
          value={input} onChange={e => setInput(e.target.value)}
          onKeyDown={e => e.key === 'Enter' && send()}
          placeholder="Ask about Gourav's work..."
          style={{ flex:1, background:'transparent', border:'none', outline:'none', color:'#F0F4F8', fontSize:14 }}
        />
        <button onClick={() => send()} disabled={streaming} style={{
          padding:'6px 14px', background:'#00D9FF15', border:'1px solid #00D9FF',
          borderRadius:8, color:'#00D9FF', cursor:'pointer', fontSize:13,
        }}>→</button>
      </div>
    </div>
  )
}
```

## PRIORITY 10 — EMPTY SPACE FIX (Introduction ↔ Expertise Spectrum)

### Root Cause

The gap between "MY INTRODUCTION / THE PIVOT" and "EXPERTISE SPECTRUM / DUAL TRACK" sections is likely caused by:

1. A** **`min-height` or fixed height on either section
2. `margin-bottom` /** **`padding-bottom` set too large
3. A hidden/failing Three.js Canvas holding space
4. An animated element (GSAP) that targets a height property and leaves dead space

### Fix

```css
/* Find and fix in globals.css or section component styles */

/* Remove any min-height on About/Intro section: */
.about-section { min-height: unset !important; }
.pivot-section { min-height: unset !important; }

/* Remove excessive bottom padding: */
.section-wrapper { padding-bottom: clamp(48px, 8vw, 80px); }
/* NOT: padding-bottom: 200px or height: 100vh */

/* If a Canvas element is causing it: */
.hero-canvas-wrapper {
  height: 0 !important;  /* temporarily to diagnose */
}
```

### Debug Steps for Dev

```
1. Open DevTools → Elements tab
2. Hover over the empty space area
3. Check which element is highlighted — note its class/id
4. Check computed styles: what is its height? margin? padding?
5. Look for: position:absolute elements that accidentally push flow
6. Check GSAP ScrollTrigger: any pinned sections in that area?
   gsap.globalTimeline.getChildren() — log all tweens, check for height animations
```
